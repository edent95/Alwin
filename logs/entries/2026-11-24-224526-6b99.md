- learned:
  - [knowledge] Sveltia CMS Additions 1.0.0 设置向导建 GitHub App 前会不带身份调 `GET /users/<owner>`,从 Cloudflare Workers 出去常被 GitHub 限流,页面只显示「GitHub responded with an error」;`wrangler tail` 看不到细节,要读 `@sveltia/cms-additions/lib/git/github/app.js`。

  - [knowledge] 私有 GitHub App 用 `gh api /apps/<slug>` 查会 404(用户 OAuth token 看不到),App ID 要在 github.com/settings/apps/<slug> 页面上看。
  - [knowledge] 要「谁都不能强推 / 删分支」又要「某个 App 免检查直接提交」,拆两条 ruleset:前者无 bypass,后者只放 required_status_checks 并给 App bypass。
  - [knowledge] 在 monorepo 的子目录里 `pnpm install` 一个模板会被当成 workspace 成员,依赖装不进来;复制到仓库外再 `pnpm install --ignore-workspace`。
