## 2026-11-26

### [E-2026-11-26-182135-52f0] 联系点击发 GA4 事件 contact(给 GA4 当关键事件用)

- type: feat
- scope: analytics
- impact: module
- why: GA4 唯一的关键事件是新建资源自带的 purchase,博客不卖东西,永远 0 次;面板 SEO 一直报「GA4 没有记录关键事件」高危。网站已经有联系渠道,改成量「访客有没有来联系」。
- changed:
  - `script.js` 末尾一个委托点击监听:点 WhatsApp 链接(项目卡、「在 WhatsApp 问我」)、页脚联系区渠道(Facebook / Instagram / DAPSY)、mailto / tel → `gtag('event', 'contact', { method, link_url, placement })`。导航里跳到 #contact 的锚点不算。
- ripples:
  - **GA4 后台要把 `contact` 标成关键事件**才会计入关键事件(管理 → 关键事件 → 新建,名字 `contact`);面板的 GA4 授权只读,改不了后台。
  - 页脚联系区新加的渠道自动算进来(按 `.channels` 判);别处新加的联系链接要是 WhatsApp / mailto / tel 才算,否则要改这个监听。
  - link_url 去掉了 `?text=`(WhatsApp 开场白里带项目名),不把文字传给 GA。
- verified: `npm run check` 通过;本机预览 + 无界面 Chrome 点 Facebook、Instagram、项目卡 WhatsApp,`dataLayer` 依次出现 3 个 contact 事件(method facebook / instagram / whatsapp),点导航 #contact 不出事件。
- keywords: GA4, 关键事件, key event, contact, 联系, WhatsApp, gtag, dataLayer, 埋点, analytics
- learned: [knowledge] GA4 新建媒体资源自带 purchase 关键事件,不卖东西的站要自己定一个关键事件(如联系点击),否则「关键事件 0」是假警报。[knowledge] 页面用 `function gtag(){}` 全局声明时,测试里用 defineProperty 包装 window.gtag 会被声明覆盖,改读 window.dataLayer 验证。
