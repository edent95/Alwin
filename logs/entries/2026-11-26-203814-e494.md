## 2026-11-26

### [E-2026-11-26-203814-e494] 全站网址去掉 .html;观点网址改成关键词网址名(去日期),旧网址自动跳转

- type: feat
- scope: seo
- impact: cross-cutting
- why: 用户:「整个 website format,用 .html 很不专业,slug 帮我安排」。原观点网址是「日期 + 英文题目截 40 字」,截出半个词(…-agreement-in、…-numbe)。
- changed:
  - 站内链接、canonical、og:url、sitemap、llms.txt、JSON-LD 一律用 `/about`、`/gallery`、`/views/<网址名>`;GitHub Pages 自动对应 `.html` 文件(上线前 curl 实测 /about 200)。
  - `src/pages/view.mjs` `viewSlug` = 文件名去掉 `YYYY-MM-DD-`;8 篇观点 `git mv` 成关键词文件名(如 `penang-perak-water-supply-agreement-rm24-6-billion`)。
  - 根目录 `redirects.json` + `scripts/build.mjs`:在旧路径写跳转页(canonical + noindex + meta refresh + location.replace 保留 ?lang=);构建检查网址名格式与重复。`check-i18n` 跳过跳转页。
  - `edit/app.js`:新观点文件名用 `wordSlug`(整词截到 60 字、去头尾虚词);发布后「看网页」链接不带 .html。
  - `scripts/serve.mjs` + `.worktree-preview.json`:本机预览认无后缀网址。
  - `content/about.json`:`index.html#stance` → `/#stance`。AGENTS.md 补两条硬约束。
- ripples:
  - **改观点文件名 = 改网址**:旧网址要加进 `redirects.json`,否则外面分享出去的链接 404。Sveltia `/admin` 新建观点的文件名规则仍是它自己的(admin/config.yml 的 slug 设置),和简易后台不同;需要时再统一。
  - GitHub Pages 不能发 301,旧网址靠跳转页 + canonical,Search Console 里旧网址会显示「重复网页,已选 canonical」,属正常。
  - 跳转页是 noindex,三语检查已跳过;别的脚本遍历 `_site/views/*.html` 时也要跳过它们(含 `<meta name="robots" content="noindex">`)。
  - 本机预览不能再用 python http.server(/about 会 404)。
- verified: `npm run check` 通过(11 页);本机预览 curl:/、/about、/gallery、/views/<新名> 都 200,旧 .html 和旧无后缀网址都 200 并跳到新网址(截图确认 ?lang=en 保留);首页卡片链接、canonical 都不带 .html。
- keywords: clean URL, 无后缀网址, .html, slug, 网址名, redirects.json, 跳转, canonical, sitemap, GitHub Pages, serve.mjs
- learned: [knowledge] GitHub Pages 对 `/about` 会自动伺服 `about.html`(200,不跳转),静态站要干净网址只需把链接 / canonical / sitemap 改成无后缀,不用改成 about/index.html(那样会多一次 /about → /about/ 的 301);但 python http.server 不认,本机预览要自己写个带 .html 回退的小服务。
