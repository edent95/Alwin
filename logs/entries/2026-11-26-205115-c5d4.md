## 2026-11-26

### [E-2026-11-26-205115-c5d4] 三语分网址:英文为主在根目录,马来文 /ms/,中文 /zh/,互标 hreflang

- type: feat
- scope: seo, i18n
- impact: cross-cutting
- why: 三语原本同一网址靠 JS 切换,搜索引擎只读到马来文默认文字,英文 / 中文读者搜不到。用户:「做,都是英文为主,然后 malay 也要」。
- changed:
  - `src/h.mjs`:`setLang` / `lang()` 当前构建语言,`v()` / `T()` 取它;`P()` 给站内页面链接加语言前缀,`link()` 自动用。
  - `scripts/build.mjs`:每页(首页、about、gallery、每篇观点)按 en / ms / zh 各写一份到 `_site/`、`_site/ms/`、`_site/zh/`;sitemap 改为构建生成(33 条,每条带 3 语 + x-default 的 xhtml:link),删掉根目录 `sitemap.xml`;跳转页 `lang="en"`。
  - `src/layout.mjs`:`<html lang>`、canonical、hreflang ×4、og:locale 按语言;语言按钮从 `<button>` 改成指向对应语言网址的 `<a hreflang>`(EN / BM / 中文);导航链接过 `P()`。
  - `src/pages/view.mjs`、`index.mjs`:og / twitter / JSON-LD 取当前语言,ProfilePage url 按语言。
  - `script.js`:不再在页内换语言;用页面语言跑一次 setLang(JS 渲染的卡片),`?lang=xx` 跳到对应网址,从站外进来且 localStorage 存过别的语言时跳过去;点语言按钮记住选择并带上 #锚点。
  - `styles.css` `.lang a`;`gallery.js` 默认语言 en;`check-i18n` 查三个语言目录;`llms.txt` 改英文并列出 /ms/、/zh/;AGENTS.md 改硬约束。
- ripples:
  - **根目录现在是英文**:以前 alwinlim.com/ 默认马来文。没存过语言偏好的读者会看到英文;Alwin 分享马来文要用 /ms/ 的链接。
  - 模板里写死 `.ms` 或直接写 `href="/about"` 都会在别的语言页出错(前者显示马来文,后者跳回英文版);新加页面也要进 build.mjs 的 `pages` 列表才会三语各一份、进 sitemap。
  - `redirects.json` 的旧网址只跳英文版。
  - 简易后台 / Sveltia 发布后的「看网页」链接是英文版。
  - Search Console:上线后重新提交 sitemap.xml;以前收录的 / 是马来文,换成英文后会重新评估。
- verified: `npm run check` 通过(33 页,三语各 11);本机预览 curl:/、/ms/、/zh/、/about、/ms/about、/zh/gallery、/views/<名>、/zh/views/<名> 都 200,/ms → 301 /ms/;马来文文章页 canonical、hreflang、语言按钮链接、导航链接都带 /ms/;截图:英文首页、`/?lang=zh` 跳到中文首页且 JS 卡片为中文。
- keywords: hreflang, 多语言, i18n, /ms/, /zh/, x-default, 英文为主, 语言切换, sitemap, canonical, P(), setLang
- learned: [knowledge] 静态多语站把「JS 切换 data-* 文字」改成「每语言一份页面」时,保留 data-* 和一次 setLang(页面语言) 能让 JS 渲染的卡片不用改;语言按钮改成 `<a hreflang>` 让搜索引擎能顺着链接发现其他语言版本。
